# Coching_AI — Proje Belleği

## Ne inşa ediyoruz
Eda Cangert'in koçluk merkezi için web/mobil bir uygulama. **İki müfredat:** 7 ve 8. sınıf LGS'ten, 9-12. sınıf ve mezunlar YKS'ten sorumlu — ayrım öğrencinin sınıfından türetilir (bkz. `src/lib/curriculum.ts`). Web dashboard tarafı için ilk tasarım turu tamamlandı: "Netlik" adlı koç paneli, 5 ekran (Koç Paneli, Öğrenci Profili, Konu Yeterlilik Haritası, Deneme Girişi, Haftalık Görüşme). Tasarım artifact'i: https://claude.ai/code/artifact/04e9bd11-0c63-4c43-b126-6fe457d037e8

Yazılım tarafı tamamlandı: **Vite + React + TypeScript + Supabase**. Auth, tasarım sistemi, routing/layout ve tüm ana ekranlar (Koç Paneli, Öğrenciler, Konu Yeterlilik Haritası, Deneme Girişi, Haftalık Program, Devamsızlık Takibi, Haftalık Görüşme, Müfredat, Tercih Sihirbazı, Mobil Öğrenci & Veli Portalı, Yardım) gerçek Supabase sorgularına ve veritabanı tiplerine bağlı olarak çalışmaktadır. Şema: `supabase/schema.sql` (idempotent — tekrar tekrar güvenle çalıştırılabilir). Öne çıkan özellikler:
- **Çok Kurumlu Yapı & Rol Tabanlı Yetki (RBAC)** (`/yonetim/*`, `/kayit`): Çoklu kurum (multi-tenancy) mimarisi, 22 dinamik izin hakkı, özel rol oluşturma (`/yonetim/roller`), e-posta ile üye davet etme ve kayıt akışı (`/kayit`), kurum içi izole yetki denetimi (`AccessContext`, `RequirePermission`) ve koçluk kilidi arayüzü (`CoachingLockedState`).
- **Öğrenciler**: ekleme/düzenleme/arşivleme/kalıcı silme, profil fotoğrafı (Supabase Storage), öğrenci + veli telefonu, mobil erişim kodu (PIN) üretme ve WhatsApp ile "Öğrenci Linki" / "Veli Linki" gönderme.
- **Tercih Sihirbazı** (`/tercih`): YÖK Atlas REST API'den derlenmiş ~66.400 üniversite programı, 11 kriterli filtreleme, başarı sırası aralığı, Türkçe-duyarsız arama (PostgREST `imatch`), ulaşılabilirlik durumu (Ulaşılabilir/Riskli/Zor) ve çıktı alma/WhatsApp paylaşma.
- **Devamsızlık Takibi** (`/devamsizlik`): Oturum türü (birebir/etüt/vb.), mazeret notu, WhatsApp bildirim açılış takibi, dürüst damgalama ("gönderildi" değil "WhatsApp açıldı"), "Takip gerekli" eşik rozetleri ve veli özet mesajı.
- **Mobil Öğrenci & Veli Portalı** (`/portal`, `/ogrenci`, `/veli`): erişim koduyla (PIN) giriş, SECURITY DEFINER RPC katmanı (`portal_login`, `portal_dashboard`, `portal_set_task_completed`, `portal_add_exam`), öğrenci görev tamamlama + bölüm bazlı deneme girişi, veli için salt-okunur özet. Rol renkleri `src/lib/portalTheme.ts` (öğrenci indigo, veli teal).
- **Yardım** (`/yardim`): ekran ekran kullanım rehberi + **Sürüm Geçmişi sekmesi** (`?sekme=surum`; v0.24'e kadar). Mobil portal kartında tıklayınca büyüyen ekran görüntüleri var (`public/yardim/*.webp`).
- **Müfredat: YKS / LGS ayrımı** (`/mufredat`): `subjects.curriculum` ('YKS'|'LGS'), `subjects.grades` **ve** `topics.grades` (sınıf etiketi dizisi; **boş = geçerli tüm sınıflar**), `subjects.katsayi`. Görünürlük TEK KAYNAK `src/lib/curriculum.ts` → `gradeCurriculum()` (7./8. ⇒ LGS, diğerleri + Mezun ⇒ YKS), `subjectAppliesTo()`, `topicAppliesTo()`. Ders/konu listeleyen her ekran bunları çağırır, mantığı kopyalamaz. **Süzme ders değil KONU seviyesinde** — LGS'te aynı ders (örn. Türkçe) hem 7 hem 8'e ait olabilir, konular ayrışır. LGS öğrencisinde Alan (track) yok → `students.track` **nullable**. Canlı: LGS 7 ders (7. sınıf 55 konu + 8. sınıf 47 konu), YKS 14 ders / 187 konu (etiketsiz = tüm YKS sınıfları). Yükleyiciler: `npm run seed:lgs` (8. sınıf), `npm run seed:lgs7` (7. sınıf + geriye dönük 8. sınıf damgalaması) — ikisi de **hiçbir şey silmez**, idempotent.
- **LGS Deneme Girişi**: `mock_exams.exam_type` = 'TYT'|'AYT'|**'LGS'**. Sınav türü öğrencinin sınıfına kilitli. ⚠️ **Net formülü DB'de generated column**: `correct_count - wrong_count / wrong_penalty`. `mock_exam_sections.wrong_penalty` default **4** (YKS), LGS satırlarında **3** — LGS'te 3 yanlış 1 doğruyu götürür. Ceza istemciden alınmaz, `portal_add_exam` sunucuda türetir. **Gerçek 500'lük LGS puanı ÜRETİLMİYOR** (merkezî sınav istatistiği gerekir); yerine katsayılı `weightedNet()` gösteriliyor ve arayüzde "LGS puanı değildir" diye etiketleniyor — buna asla "puan" deme.
- **Yedekleme & Geri Yükleme** (`npm run backup`, `npm run restore`): 18 tablodan **16'sını** (`university_rankings` ve `permission_catalog` hariç — script'ten yeniden üretilebilen referans veri) ve `student-photos` storage bucket'ını tarihli JSON + görsel yedeği olarak indirir. `.github/workflows/backup.yml` ile her gece saat 05:00 TSİ otomatik çalışır, istenirse gizli (private) GitHub reposuna aktarır.

Service-role key kullanarak RLS kurallarını bypass eden ve `src/tytSubjects.json` müfredatını seede hazır hale getiren bir seed script'i (`scripts/seedSupabase.ts`) ve `npm run seed` komutu var — **⚠️ dikkat: bu script `subjects` tablosunu tamamen silip eski listeyle dolduruyor, cascade ile öğrenci verisini de siliyor, tekrar çalıştırmadan önce coordination.md'ye bak.** Proje `npm run build` ile hatasız derleniyor ve **canlı yayında**: https://netlik-koc-paneli.vercel.app — Vercel GitHub reposuna bağlı, **`main`'e push edilince otomatik deploy oluyor** (elle `vercel --prod` de mümkün). Deploy doğrulaması: yereldeki `dist/assets/index-*.js` hash'i ile canlı `index.html`'deki hash eşleşene kadar bekle. Kullanıcı için ekran görüntülü kullanım rehberi: https://claude.ai/code/artifact/7b356fea-fcd3-4dda-af5f-af6044b5e3c5

## Bilinmesi gereken tuzaklar
- **Şema değişikliğini uygulayan kullanıcıdır.** Ortamda DDL çalıştıracak bir yol yok (`psql` kurulu değil, DB parolası yok, Supabase Management API erişimi yok). `supabase/schema.sql`'i güncelle, sonra kullanıcıdan **Supabase SQL Editor'de çalıştırmasını iste** — dosya idempotent olmalı ki tekrar tekrar çalıştırılabilsin. SQL'i teslim etmeden önce Docker'da (`docker run postgres:16`) stub tablolarla sözdizimi/mantık doğrulaması yapılabilir.
- **`create table if not exists` mevcut tabloyu HİÇ güncellemez.** Tablo zaten varsa blok tamamen atlanır — içine yazdığın yeni kolon oluşmaz. Var olan bir tabloya eklenen her kolon ayrıca `alter table … add column if not exists` ile eklenmeli, **ve o kolona dokunan her indeks/constraint/`alter column` bu `alter` satırlarının ALTINDA olmalı.** Aksi halde boş DB'de sorunsuz geçen dosya gerçek veritabanında `42703: column "…" does not exist` verir. **Docker doğrulamasını boş DB'de yapmak bu hata sınıfını yakalayamaz** — testi *önce eski/canlı şema, sonra yeni şema, sonra bir kez daha* diye koştur. (2026-08-13'te RBAC şemasında tam bu hata yaşandı: `students(institution_id)` indeksi kolonu ekleyen `alter`'dan önceydi.)
- **Koda gömülü ders adı listesi yazma.** Ekranlar dersi `subject_id`/join üzerinden gruplamalı. 2026-08-21'de öğrenci profilindeki Konu Yeterliliği sekmesi `subjectConfig` diye sabit 10 isimlik bir eşleşme kullanıyordu (`'Türkçe'`) ama canlı adlar `TYT Türkçe` idi → 14 dersten yalnız 4'ü görünüyordu, **hiç hata vermeden**. Aynı sınıf tuzak: `subjects.sort_order` müfredat başına ayrı bir uzay (YKS 1..14, LGS 1..6) — sıralama/`max(sort_order)` hesabı daima `curriculum`'a göre daraltılmalı.
- **Generated column ALTER edilemez.** `mock_exam_sections.net` böyleydi ve formülü YKS'e gömülüydü. Değiştirmek için `drop column` + `add column ... generated always as (...)` gerekir. Veri kaybı yok (türetilmiş) ama **idempotentlik guard'ı şart**: `pg_get_expr(d.adbin, d.adrelid)` ile mevcut ifadeyi oku, aradığın kolonu içermiyorsa drop+add yap. Yoksa şema her koşuda kolonu gereksizce yeniden kurar.
- **Yeni veri "sadece eklenecek" sanma — önce ADLARIN çakışıp çakışmadığına bak.** 7. sınıf müfredatı geldiğinde "şema değişmeyecek" denmişti; beş ders adı 8. sınıfla birebir aynı çıktı (`Türkçe`, `Matematik`…) ve `unique(curriculum, name)` yüzünden ikinci satır açılamadı. Çözüm `topics.grades` kolonunu eklemek oldu. Bir hiyerarşide üst seviye (ders) etiketliyken alt seviye (konu) etiketsizse, alt seviye **sessizce her yere** görünür.
- **"Script'i çalıştırma" talimatı ortam değişkenini kaldırmakla korunmaz.** Seed script'leri `.env.local`'i **kendileri** okuyor; `unset VITE_SUPABASE_URL` işe yaramaz, script gerçek Supabase'e bağlanır. 2026-08-21'de bir ajan sözdizimi denemek için çalıştırdı ve canlıya bağlandı (yalnız select çalıştı, yazma olmadı). Sözdizimi kontrolü için `tsc --noEmit` ya da dosyayı geçici olarak yeniden adlandırmak gerekir.
- **Mobil portalda `supabase.from(...)` KULLANMA.** Öğrenci/veli giriş yapmış bir Supabase kullanıcısı değil; anon rolünün hiçbir tabloda yetkisi yok, sorgu sessizce boş döner. Veri `portal_*` SECURITY DEFINER RPC'lerinden gelir.
- **Postgrest tip çıkarımı:** `src/types/database.ts`'teki satır tipleri `type` olmalı, `interface` DEĞİL — `interface` sessizce `never`'a düşürüyor.
- **Supabase 1000 satır cap'i:** tek `.select()` en fazla 1000 satır döndürür (`.limit()` bile aşmaz). Çok satırlı okumada `count` + `.range()` sayfalaması kullan.
- **Fonksiyonu anon'a kapatmak:** `revoke ... from public` YETMİYOR — Supabase, `public` şemasındaki fonksiyonlara `anon`/`authenticated` rollerine **doğrudan** execute veriyor. Doğrusu: `revoke all on function f(args) from public, anon, authenticated;` (definer fonksiyonlar owner olarak çalıştığı için birbirini yine çağırabiliyor).
- **supabase-js toplu insert:** dizi halinde insert ederken anahtarları birleştirip eksik olanlara `null` yolluyor. Bir satırda alan verip diğerinde vermezsen `not-null` hatası alırsın — toplu insert'te tüm satırlara aynı alanları yaz.
- **Portal sayfalarında renk:** bu sayfalar zemini/kartları sabit açık renkte çiziyor, `var(--token)` karanlık temada dönüp okunmaz hale getirir → `portalTheme.ts`'te sabit hex kullanılıyor. Metin ve rozet dolgusu daima `accentStrong` (kontrast), `accent` yalnız metin olmayan alanlarda.
- **CSS token adı:** indigo'nun açık tonu `--indigo-050` (sıfır dolgulu). `--indigo-50` diye yazılırsa sessizce hiç uygulanmıyor — bu tuzağa bir kez düşüldü. Aynı sessizlik iki yerde daha var: **var olmayan token** (`--surface-elevated`, `--ink-muted`, `--accent` YOK; doğrusu `--surface-alt`, `--ink-faint`, `--indigo-600`) ve **tanımsız CSS sınıfı**. 2026-08-16'da `modal-header`/`modal-actions`/`btn-icon`/`form`/`alert*`/`badge*`/`table` sınıfları JSX'te kullanılıyordu ama `global.css`'te hiç tanımlı değildi — modallar ham HTML akışına düşmüştü. **Tailwind bu projede KURULU DEĞİL**; `className="flex gap-2 text-[10px]"` gibi utility sınıfları hiçbir şey yapmaz. Ayrıca aynı seçiciyle ikinci bir blok açmak birincisini sessizce ezer.
- **Supabase Auth URL ayarı (e-posta bağlantıları):** `redirectTo` ancak **Redirect URLs izin listesinde** olan adrese gider; listede yoksa Supabase sessizce **Site URL**'e düşer. Bu ayar `localhost:3000`'de kalmıştı ve şifre sıfırlama/kayıt onayı bağlantılarının hepsi oraya gidip `otp_expired` veriyordu (2026-08-16'da yaşandı). Doğrusu: **Authentication → URL Configuration** → Site URL `https://netlik-koc-paneli.vercel.app`, Redirect URLs'e `https://netlik-koc-paneli.vercel.app/**` (+ yerel geliştirme için `http://localhost:5173/**` — Vite'ın portu 5173, 3000 değil). **E-posta onayı açık** (`mailer_autoconfirm = false`): davet edilen kişi doğrulama maili gelmeden giriş yapamaz.

## Bağlam & Yedekleme Kurulumu
- Domain: YKS koçluk — öğrenci haftalık çalışma takibi, deneme sonuçları, konu bazlı yeterlilik (yeterli/gelişiyor/kritik/ölçülmedi).
- Track'ler: SAY, EA, SÖZ. Sınıf: 12. Sınıf / Mezun.
- Net hesaplama: Net = Doğru − Yanlış/4 (TYT: Türkçe 40, Matematik 40, Fen 20, Sosyal 20 soru).
- Manuel Yerel Yedek: Terminalde `npm run backup` (çıktı `backups/YYYY-MM-DD/`).
- Otomatik Private GitHub Yedeği: GitHub reposunda `Settings -> Secrets -> Actions` kısmına `BACKUP_REPO_TOKEN` (PAT), `BACKUP_REPO_URL` (`github.com/KULLANICI/GIZLI-REPO.git`), `VITE_SUPABASE_URL` ve `SUPABASE_SERVICE_ROLE_KEY` eklendiğinde her gece otomatik push eder.
- Tüm UI metni Türkçe.
